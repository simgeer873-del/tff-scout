# TFF Scout Modernizasyon Prototipi — Tam Demo

Hazırlayan: **Simge Er**

Bu sürüm, yöneticinin tarayıcıdan gezebileceği kapsamlı çalışan demo prototipidir.

## Dahil edilen modüller

- Ana Sayfa
- Milli Takımlar
- A Milli Takım: Genel Bakış, Kadro, Maçlar, Videolar, İstatistikler, Raporlar
- Karmalar
- Rakipler
- Futbolcularım
- Popüler Oyuncular
- Kulüpler
- Maç & Video Analiz
- İstatistikler
- Oyuncu Raporları
- Güncel Videolar
- Esame Raporu
- Maç Raporları
- Gelişim Ligi Raporları
- Antrenman Planları
- Kulüp Gelişim
- Oyuncu Eşleştirme
- Teknik Testler
- Sakatlıklar
- Scout Profilleri
- Yetenek Başvuruları
- Doküman Yönetimi
- İzleyici Atama
- Kullanıcı Yönetimi
- Mesajlar
- Dark / Light tema
- Aktif menü vurgusu
- Referans görsele uyarlanmış Futbolcu Ara ekranı
- Çalışan filtreler, sıralama ve oyuncu karşılaştırması
- Radar analizi, performans özeti, ısı haritası ve istatistik grafiği

## Çalıştırma

`index.html` dosyasını açın.

## GitHub Pages

Repo'yu GitHub'a yükleyin:
Settings → Pages → Deploy from a branch → main / root

## Önemli

Bu demo gerçek TFF veritabanı veya API'sine bağlı değildir. Veriler yalnızca prototip amaçlıdır.
